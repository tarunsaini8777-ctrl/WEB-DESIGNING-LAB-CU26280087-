# Lab Sheet 3 — JavaScript

21 practice problems. Every question has its own self-contained `.html` file (HTML + CSS + JavaScript in one file). Just open the file in a browser — no internet or libraries needed. Press **F12** to see console output.

> Q1 uses `prompt()` and `alert()` dialogs: click the button, then answer the dialogs. Q16 uses generated images, so it works offline (replace the `src` values to use your own pictures).

## Questions

- [Q1](Q01_prompt_arithmetic.html) — Write a JavaScript program to accept two numbers via prompt dialogs, perform arithmetic operations, and display the result using console.log and alert.
- [Q2](Q02_prime_or_composite.html) — Implement a JavaScript function that checks whether an input number is prime or composite, outputting the result dynamically into a web page div.
- [Q3](Q03_grade_if_else_switch.html) — Write a script using JavaScript conditional statements (if-else, switch) to determine student grade letter based on numerical marks.
- [Q4](Q04_fibonacci_loops.html) — Create a JavaScript loop (for, while, do-while) program to generate and print the Fibonacci series up to n terms on the webpage.
- [Q5](Q05_reverse_palindrome.html) — Write a JavaScript function that takes a string as input, reverses it, and checks if it is a palindrome.
- [Q6](Q06_array_methods.html) — Implement an array manipulation script in JavaScript that adds, removes, sorts, and filters elements using built-in array methods (push, pop, map, filter).
- [Q7](Q07_student_object_this.html) — Write a JavaScript program implementing a custom object representing a student with properties and methods, demonstrating this keyword usage.
- [Q8](Q08_calculator.html) — Create an interactive calculator web page using JavaScript event listeners (addEventListener) for click events on buttons.
- [Q9](Q09_dynamic_dom_elements.html) — Write a script that dynamically creates and appends new DOM elements (createElement, appendChild) based on user text input.
- [Q10](Q10_password_match_validation.html) — Implement real-time form validation in JavaScript checking if password and confirm password fields match before submission.
- [Q11](Q11_mouseover_mouseout.html) — Write a JavaScript event handler for mouseover and mouseout events to change the background color of an HTML element dynamically.
- [Q12](Q12_digital_clock.html) — Create a digital clock web page using JavaScript setInterval and Date object to display live time updating every second.
- [Q13](Q13_closure_counter.html) — Write a JavaScript program implementing closure to maintain a private counter variable with increment and decrement methods.
- [Q14](Q14_try_catch_finally_json.html) — Implement exception handling in JavaScript using try...catch...finally blocks while parsing a JSON string.
- [Q15](Q15_es6_features.html) — Write a script utilizing arrow functions, template literals, and destructuring assignment syntax (ES6 features).
- [Q16](Q16_image_gallery_slider.html) — Create a dynamic image gallery slider using JavaScript arrays to cycle through image sources upon clicking 'Next' and 'Previous' buttons.
- [Q17](Q17_count_vowels.html) — Write a JavaScript function that counts the occurrences of vowels in a given paragraph string.
- [Q18](Q18_todo_list.html) — Implement a simple todo list application in JavaScript allowing users to add and delete tasks from an unordered list.
- [Q19](Q19_keyboard_events.html) — Write a script that captures keyboard events (keydown, keyup) and displays the pressed key code and character on the screen.
- [Q20](Q20_table_generator.html) — Create a dynamic table generator in JavaScript that takes row and column counts from user inputs and renders a populated HTML table.
- [Q21](Q21_callbacks_settimeout.html) — Write a JavaScript program demonstrating callback functions and asynchronous behavior using setTimeout.
