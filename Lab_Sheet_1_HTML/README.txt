LAB SHEET 1 — HTML

This folder contains Q01.html through Q25.html.
Each file includes the question as an HTML comment and its solution code.

Image questions (Q11–Q14 and Q15 local image) use images/flower.jpg as an example.
Create an images folder in your repository and add a flower.jpg image, or change the src value to the path of an image you have.

GitHub upload:
1. Extract this ZIP file.
2. Open your GitHub repository.
3. Select Add file > Upload files.
4. Upload Q01.html through Q25.html and README.txt.
5. Click Commit changes.
