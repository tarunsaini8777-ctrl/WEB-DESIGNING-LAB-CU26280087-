# Online Bookstore (PHP + MySQL + Bootstrap)
1. Import `database.sql` (creates DB `bookstore`, tables and sample books + admin user).
2. Set DB credentials in `config.php`.
3. Run `php -S localhost:8000` in this folder (or place in XAMPP `htdocs/bookstore`) and open http://localhost:8000
