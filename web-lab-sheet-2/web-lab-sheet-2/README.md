# Lab Sheet 2 — HTML Forms & CSS

22 practice problems. Every question has its own `.html` file (open it in any browser). Questions that need more than one file are grouped by their number:

- **Q1** → `Q01_form_controls.html` + external `Q01_style.css`
- **Q3** → `Q03_frameset.html` + `Q03_header.html`, `Q03_nav.html`, `Q03_content.html` (the three frames)
- **Q11** → `Q11_specificity_contact.html` + external `Q11_style.css`

Keep the files of one question in the same folder. All other questions use internal CSS (one self-contained file). No internet connection or libraries are needed.

> Q3 uses `<frameset>`, which is obsolete in HTML5 (legacy practice, as the question says); Q4 shows the modern Flexbox replacement.

## Questions

- [Q1](Q01_form_controls.html) — Create an HTML form with text input, password, radio buttons, checkboxes, dropdown select, and a textarea, styled entirely with external CSS.
- [Q2](Q02_registration_validation.html) — Design a student registration form incorporating HTML5 validation attributes (required, minlength, maxlength, pattern, type='email').
- [Q3](Q03_frameset.html) — Implement a multi-column layout using HTML <frameset> and <frame> tags (Note: legacy support practice), containing a navigation frame, header frame, and content frame.
- [Q4](Q04_flexbox_layout.html) — Create a modern webpage layout replicating frame-like behavior using CSS Flexbox (display: flex) instead of HTML frames.
- [Q5](Q05_login_card.html) — Design a user login interface inside a centered card container using CSS box-shadow, border-radius, and absolute positioning.
- [Q6](Q06_grid_form.html) — Write a CSS stylesheet utilizing CSS Grid to arrange form elements into a clean two-column grid layout.
- [Q7](Q07_focus_feedback.html) — Build an interactive feedback form where input fields change border color and background tint on :focus pseudo-class.
- [Q8](Q08_file_upload_button.html) — Create an HTML form featuring file upload (type='file') and a styled custom submit button with CSS transitions on :hover and :active states.
- [Q9](Q09_fieldset_survey.html) — Implement a survey form utilizing grouped form controls using <fieldset> and <legend> tags, styled with custom padding and margins.
- [Q10](Q10_table_form.html) — Design a CSS-styled data entry table embedded inside a form container with alternating row colors and hover effects.
- [Q11](Q11_specificity_contact.html) — Write an HTML document utilizing inline, internal, and external CSS stylesheets to style a contact form simultaneously, observing specificity rules.
- [Q12](Q12_payment_responsive.html) — Create a responsive payment gateway checkout form using CSS media queries to adjust input widths on mobile screens.
- [Q13](Q13_custom_checkbox_radio.html) — Implement custom styled checkboxes and radio buttons using CSS pseudo-elements (::before and ::after) and sibling selectors (~).
- [Q14](Q14_range_number.html) — Design an HTML form with a range slider (type='range') and number input, displaying live unit labels.
- [Q15](Q15_search_expand.html) — Build a search input box that expands in width smoothly using CSS transition when focused.
- [Q16](Q16_float_evaluation.html) — Create a structured employee evaluation form using CSS float and clear properties for alignment.
- [Q17](Q17_hidden_fields.html) — Write an HTML form incorporating hidden input fields (type='hidden') to pass session data securely.
- [Q18](Q18_contact_page_flex.html) — Design a responsive contact us page featuring an embedded form on one side and company location details on the other using CSS Flexbox.
- [Q19](Q19_typography_form.html) — Implement CSS typography rules (font-family, line-height, letter-spacing, text-transform) across all labels and placeholders in a registration form.
- [Q20](Q20_multistep_onboarding.html) — Build a multi-step user onboarding form layout using CSS display properties (display: none / block) to simulate step progression.
- [Q21](Q21_accessible_form.html) — Create an accessible form where every <input> is explicitly linked to its corresponding <label> using the for and id attributes.
- [Q22](Q22_floating_label_newsletter.html) — Design a newsletter subscription widget with a floating label effect using CSS positioning.
